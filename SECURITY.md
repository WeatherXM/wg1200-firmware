# Security Policy

WeatherXM takes the security of its hardware, firmware, and decentralized physical infrastructure network seriously.

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

If you believe you have discovered a vulnerability in the WG1200 firmware or related systems, please report it via one of the following channels:

1. **GitHub Private Vulnerability Reporting**:
   * Navigate to the **Security** tab of the repository on GitHub and select **Report a vulnerability**.
2. **Email**:
   * Contact the WeatherXM Security Team at: **`security@weatherxm.com`**

### What to Include in Your Report

To help us triage and resolve the issue quickly, please provide:
* Description of the vulnerability and its potential impact
* Affected firmware versions and hardware models
* Detailed proof-of-concept (PoC) or reproduction steps
* Any potential remediations or patches you have developed

### Response Process

* **Acknowledgment**: We aim to acknowledge receipt of your report within 48 hours.
* **Assessment**: Our engineering and security team will investigate and determine the validity and severity of the vulnerability.
* **Remediation**: Once validated, we will develop and test a fix.
* **Disclosure**: We practice coordinated vulnerability disclosure and will coordinate release timing with the reporter.
